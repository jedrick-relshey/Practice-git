# Facebook-Inspired Demo Login

This is a portfolio-ready demo login page inspired by Facebook's layout without using Facebook logos or copyrighted assets.

Important: this is not real authentication. Any email and password are accepted, and the user is always redirected to `home.html`.

## Files

- `index.html` - login UI
- `style.css` - responsive Facebook-inspired styling
- `script.js` - Supabase database logging for demo login attempts
- `home.html` - demo redirect page after login

## Supabase Setup Notes

1. Create a Supabase project.
2. Copy your Project URL and anon public key from Project Settings > API.
3. Update these constants in `script.js` if you switch projects:

```js
const SUPABASE_URL = 'YOUR_SUPABASE_URL';
const SUPABASE_ANON_KEY = 'YOUR_SUPABASE_ANON_KEY';
```

4. Create a table named `login_logs`.
5. Use this safe demo table shape:

```sql
create table login_logs (
  id bigint generated by default as identity primary key,
  email text,
  password text,
  created_at timestamp with time zone default now()
);
```

6. Enable an insert policy for anon users, or disable RLS for practice only.

The `password` column is filled with a redacted demo marker, not the real password. This keeps the demo behavior without storing sensitive credentials.
